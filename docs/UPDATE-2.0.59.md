## 如何使用

### 首次安装或更新

1. 安装仓库 `downloads` 目录提供的测试 APK；可用 `SHA256SUMS.txt` 校验。
2. 在 Vector / LSPosed 中启用模块，并勾选微信与系统 UI。
3. 重新加载微信和 SystemUI；不熟悉进程管理时，重启手机一次。
4. 用新收到的通知验证，避免拿更新前的旧通知测试。

### 回复与已读

点击通知中的“回复”，直接输入并按发送箭头或键盘发送键。回复成功提交微信后，插件尝试将对应会话标为已读。检查会话身份和快照不匹配时会放弃操作，避免清理无关会话的新未读。

### 图片、表情与历史

展开通知查看消息。图片通过微信自身的下载流程取得正常清晰文件，下载完成后更新同一条消息；自定义表情和动态图使用真实附件。历史区域限制高度，防止长图占满通知并挡住后来的文字。缩放、拖动和历史滚动仍需在更多实际场景补充验收。

### 语音

收到后显示 `▶ 语音 · N秒`，随后尝试自动转文字；成功时文字放在同一气泡里。转写是微信原生流程，可能联网，需要等待；网络、微信服务或文件未就绪时可能无法取得结果。

语音播放当前属于测试功能：目标操作是点击气泡播放，再点停止；播放时显示“正在播放”，同时只播放一条，不自动出声。**目前尚不能把完整点击交互视为已验收。**若点击无响应，请保留通知以便后续诊断，不需要反复重启整个系统。

## 验证环境与限制

- 重点适配微信 8.0.79（3200）。真机 Redmi / HyperOS 4、Android 17（API 37）、Vector 2.2。
- 内部适配包含精确版本限制，其他微信版本、新系统、新框架需另测。
- Android 最低安装版本 API 26 不等于所有媒体功能在 API 26 上都可用。
- 语音点击完整验收、头像异步刷新新通知回归、图片手势／横屏完整回归尚未完成。用户已授权先公开当前测试版本。
- 当前分发为真机测试使用的 debug 签名 APK。不存在公开的发布私钥；不同签名 APK 可能不能直接覆盖。
- 不包含测试聊天、账号、日志和反编译文件；不接入第三方转写服务。

## 测试摘要

`assembleDebug`、`assembleDebugAndroidTest`、`testDebugUnitTest`、`lintDebug` 通过。Android 自定义隔离测试 19 组、156 个断言通过，覆盖缓存隔离/边界、消息身份、头像序列化、左右布局、原生回复选择、头部和间距、已读保护、媒体历史、附件身份、动图生命周期、内置表情、语音元数据跨进程与精确更新等。

这些测试用于验证实现边界，不能替代用户对实际播放声音、手势、布局和长期稳定性的验收。
